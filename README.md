# scoop-bucket

Scoop bucket for [Curtain](https://github.com/ChachanNaman/curtain).

```powershell
scoop bucket add curtain https://github.com/ChachanNaman/scoop-bucket
scoop install curtain
```

Curtain is unsigned, so Windows SmartScreen will warn the first time it runs — click
"More info" then "Run anyway".
